# مَلَكة: brand and interface rules

Short and practical. If a rule here and the code disagree, fix one of them.

## Idea

Three motifs tell one story, in this order:

1. **نجوم (stars)**: you discover what you have. Scattered points.
2. **زخرفة (girih)**: you connect them into structure. The ten-fold rosette.
3. **حلقات (rings)**: it grows with practice. Concentric growth rings.

Use a motif only for its meaning. Stars for steps, items found, things not yet connected. The rosette for progress through the ten project steps (one petal per step). Rings for levels and growth over time. Never use them as decoration without that meaning.

Use the scale tokens (`--violet-600`) only to define new semantic tokens. Components use the semantic tokens:

- Ground and surfaces: `--bg`, `--surface`, `--surface-2`, `--well`, `--rail-bg`, `--line`, `--line-2`
- Text: `--ink`, `--ink-2`, `--ink-3`
- Brand and action: `--brand`, `--on-brand`, `--brand-wash`, `--accent` (saffron, the one primary-action colour), `--on-accent`, `--link`, `--focus`, `--em`
- State: `--status` (teal), `--status-wash`, `--status-fill`, `--bad`, `--warn-wash`
- Colour blocks, identical in both themes: `--sun`, `--violet`, `--mint`, `--coral`, `--lilac`, with `--block-ink` for text on the light ones and white on violet
- Sky tile: `--sky-a`, `--sky-b`, `--sky-ink`, `--sky-ink-2`, `--sky-ink-3`, `--gold`

Light theme: lavender paper (`--violet-100`), white cards, coloured shadows (`--shadow`, `--lift-*`). Dark theme: deep saturated violet night, luminous saffron and teal, glows instead of shadows.

### Nebula gradient

`--nebula`: `linear-gradient(100deg, violet-600, coral-500 52%, saffron-200)`.

- Allowed: the wordmark star, the ring around the primary tile, the active nav bar, the aurora field, the highlighted word in a page headline (`--nebula-text`, tuned per theme so each stop keeps 3:1 on the ground).
- Text on a gradient fill uses `--nebula-deep` (violet-700 to coral-600) with white text. Never put text on the saffron end.
- Not allowed: buttons, body text, form fields, more than one nebula element per tile.

### Rules

- One primary action per view, in saffron. Teal means state, never action.
- State is never colour alone: pair it with an icon, a number or words (tick icon plus «مكتمل», number plus «ناقص»).
- Every new text/background pair goes into `tools-contrast.mjs` and must pass: 4.5:1 for text, 3:1 for large text, icons and borders. Run `node hub/tools-contrast.mjs`.

## Shape

Radii vary on purpose: fields 10px, cards 18px, tiles 22 to 40px, and overlapping tiles get one tight corner (8 to 10px) where they tuck in. No uniform radius, no single soft shadow on everything.

## Motion

Principles: motion explains (what changed, where it went), it never blocks; transform and opacity only; one orchestrated entrance per view, then stillness except for the things that are alive (stars, the next step). Under `prefers-reduced-motion` everything is instant and the welcome is a static page. The app works with the animation files missing.

Easing: `cubic-bezier(.16,1,.3,1)` for entrances, `cubic-bezier(.2,1.5,.4,1)` for small springs. Durations: 150 to 250ms feedback, 400 to 900ms entrances.

### Helpers for section files

Add the attribute; `motion.js` does the rest after each render. They do nothing when motion is reduced or the layer is missing, and content stays visible.

| Attribute | Effect |
|---|---|
| `data-reveal` | Fades and rises into place when it scrolls into view |
| `data-reveal="words"` | Headline words rise out of a mask one after another (text and inline elements only) |
| `data-stagger="80"` | Direct children enter one after another, value is the gap in ms |
| `data-count="12"` | The number rolls like an odometer up to the value; the element's text must be the same number |
| `data-tilt` | Slight 3D tilt following the pointer (pointer devices only) |
| `data-magnet` | The element leans toward the pointer (use on one primary button) |
| `data-glow-host` | A soft light follows the pointer across the element (it needs `position:relative; overflow:hidden`) |
| `data-aurora` on a `<canvas>` | Draws the slow colour field; size and mask it with CSS |
| `data-d="120"` | Entrance delay in ms for elements that already animate in (`.bento`, `.choices`, `.plist` children) |

From script: `HubMotion.burst(el, 12)`, `HubMotion.celebrate()`, `HubMotion.turn(el)`.
